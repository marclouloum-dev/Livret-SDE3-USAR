Livret opérationnel SDE3–USAR
Ouvrir index.html dans un navigateur. Cliquez sur les cellules pour les compléter; les modifications sont enregistrées localement dans le navigateur. Imprimer / PDF permet l'impression. Exporter permet de conserver une copie HTML remplie.
Pour une installation PWA, héberger le dossier sur HTTPS (ex. GitHub Pages).
Le classeur original est inclus comme référence.
Attention : l'export HTML de Calc peut présenter des différences de pagination par rapport à l'impression native du classeur. Vérifier l'impression avant usage opérationnel.
